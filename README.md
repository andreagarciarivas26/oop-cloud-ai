# Operaciones con Números Complejos

Librería desarrollada en Python para realizar operaciones básicas con números
complejos representados mediante tuplas de la forma `(a, b)`, donde `a`
corresponde a la parte real y `b` a la parte imaginaria.

El proyecto permite realizar operaciones de suma, resta, multiplicación,
división, cálculo del módulo y conjugado de números complejos. También incluye
funciones para realizar la conversión de coordenadas cartesianas a coordenadas
polares y calcular la fase de un número complejo.

El proyecto incorpora pruebas automáticas utilizando el framework `unittest`
de Python.

---

## Getting Started

Estas instrucciones permiten obtener una copia del proyecto y ejecutarlo
localmente para realizar pruebas y modificaciones durante el desarrollo.

### Prerequisites

Para ejecutar este proyecto se necesita:

- Python 3.x
- Visual Studio Code u otro editor de código
- Terminal o consola de comandos

Python puede descargarse desde:

https://www.python.org/

El proyecto no requiere librerías externas para las operaciones implementadas.

### Installing
- Paso 1. Descargar  el proyecto
- Paso 2. Abrir la carpeta del proyecto
- Paso 3. Ejecutar el programa

#### Operaciones disponibles

- Suma
- Resta
- Multiplicación
- División
- Módulo
- Conjugado
- Conversión de cartesiano a polar
- Fase de un número complejo

## Running the tests

Las pruebas automáticas se encuentran en el archivo:

test_complejos.py

El archivo sigue la convención de nombres de unittest.

## Deployment

Este proyecto está diseñado principalmente para fines educativos.

Para utilizarlo en otro computador, es suficiente copiar los archivos:

- complejos.py
- test_complejos.py
- README.md
